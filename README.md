📦 Supply Chain & Inventory Analytics

📌 Project Overview
An end-to-end data analytics project using MySQL, Python (Pandas), and Power BI** to analyze supply chain operations, inventory levels, supplier performance, purchase orders, sales orders, and product returns.

🎯 Objectives
- Analyze inventory levels and identify stock shortages.
- Evaluate purchase order delivery performance.
- Understand sales order status and monthly trends.
- Identify inventory records below reorder points and safety stock levels.
- Build an interactive Power BI dashboard for business insights.

🛠️ Tools & Technologies
- MySQL: Data querying and analysis
- Python:Data cleaning and exploratory analysis using Pandas
- Power BI: KPI reporting and interactive dashboards

 📊 Datasets
The project covers seven datasets:
- Inventory
- Products
- Suppliers
- Purchase Orders
- Sales Orders
- Warehouses
- Returns

🔍 Key Findings
Analysis of 10,600 inventory records identified:
- 511 records below the reorder point.
- 180 records below safety stock.
- 118 records with zero stock.

Purchase order analysis also examined delivery delays and on-time performance.

 📈 Dashboard
The Power BI dashboard includes KPI cards and visualizations for:
- Sales order status
- Inventory stock status
- Purchase order delivery performance
- Product category distribution
- Monthly sales trends
